# Reproduction guide

Run all commands from the repository root after extracting the evidence release.
The commands below only use retained data and responses; none retrains policies
or calls a model provider.

## Individual commands

```bash
python scripts/reproduce_revision_primary.py
python scripts/evaluate_revision_baselines.py --bundle outputs/kbs_revision_r1_20261104/baseline_final --judge-dir outputs/kbs_revision_r1_20261104/baselines_minimax --output reproduced/minimax_added.json
python scripts/evaluate_revision_baselines.py --bundle outputs/kbs_revision_r1_20261104/deepseek_main_bundle --judge-dir outputs/kbs_revision_r1_20261104/replication_deepseek --output reproduced/deepseek_added.json
python scripts/evaluate_revision_retention.py --root outputs/kbs_revision_r1_20261104 --output reproduced/retention.json
python scripts/evaluate_kbs_external_study.py --collection outputs/kbs_external_validation_20261105/lunar --prepared outputs/kbs_external_validation_20261105/lunar_final --responses-dir outputs/kbs_external_validation_20261105/lunar_judge_minimax --provider minimax --output-dir reproduced/lunar_minimax
python scripts/evaluate_kbs_external_study.py --collection outputs/kbs_external_validation_20261105/lunar --prepared outputs/kbs_external_validation_20261105/lunar_final --responses-dir outputs/kbs_external_validation_20261105/lunar_judge_deepseek --provider deepseek --output-dir reproduced/lunar_deepseek
python scripts/evaluate_highway.py --output reproduced/highway.json
```

Use a fresh output directory for each external evaluation. `reproduce_all.py`
handles separate run directories automatically and also verifies the resulting
statistics against the archived reports.

## Interpretation and separation of information

- Controlled pairwise resampling uses policy pairs, not individual API calls.
- Repeated selection is evaluated at the retention-seed level.
- External policies are reused across comparisons; the evaluators retain
  policy/chain dependence, ambiguous references, and unresolved responses.
- Evaluation-only files contain the reference mappings and are released so the
  scoring can be inspected. They must not be added to judge prompts.
- `_private` in a historical filename means hidden from the judge, not personal
  participant information. Anonymous policy and comparison identifiers are stable.

## Reproduction levels

The supported no-key route reproduces calculations from the retained evidence.
The source also exposes the compiler, controlled generator, operational reference
rules, and external training implementations. A new end-to-end experiment requires
training resources, optional environment dependencies, and, for model selection,
the user's own credentials. Historical model availability and exact stochastic
responses cannot be guaranteed.

Original file hashes in historical manifests document provenance. Public evidence
hashes are in `sha256.json`; metadata redaction changes some original file hashes
without changing the behavioral observations, prompts, labels, or recorded choices.
Historical launch/recovery scripts were omitted from this release. Do not use
old execution manifests as commands to resume the completed experiments.
